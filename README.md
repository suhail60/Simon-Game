# 🧠 Simon Says Memory Game

A classic **Simon Says** memory game built with vanilla **JavaScript**, **HTML**, and **CSS**. The player must remember and repeat an increasingly long sequence of button presses to progress through levels.

---

## 🎮 How to Play

1. Click the **Start** button to begin the game.
2. Watch the sequence of color flashes generated by the computer.
3. Repeat the same sequence by clicking the colored boxes.
4. Each level adds a new color to the pattern.
5. If you make a mistake, the game ends and resets.

---

## ✨ Features

- Dynamic sequence generation
- Visual animations for computer and player inputs
- Level progression logic
- Game over detection and reset functionality
- Simple and clean code — great for learning JavaScript DOM manipulation
